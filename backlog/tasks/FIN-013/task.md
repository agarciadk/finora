# FIN-013 — Public landing page for unauthenticated users

## Summary

The inbox asks for a home/landing page shown outside of the authenticated app ("Añadir página de inicio fuera de usuario registrado"). Today, unauthenticated users only see the login/register pages — there's no marketing/landing page.

## User Story

As a visitor who isn't logged in,
I want a landing page that explains what Finora does,
so that I understand the product before creating an account.
