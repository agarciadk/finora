# FIN-015 — Detect duplicates during transaction import

## Summary

The inbox asks to improve the transaction import flow so the user can see potential duplicates and choose whether to import them ("Mejorar el flujo de importación de transacciones donde se puedan ver duplicados y elegir si importarlos o no"). The rule that defines "duplicate" is not specified.

## User Story

As a user importing a transactions file,
I want to see which rows look like duplicates of existing transactions,
so that I can decide whether to skip or import them anyway.
