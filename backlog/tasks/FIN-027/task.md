# FIN-027 — Loan amortization schedule

## Summary

Show a full amortization schedule (per-period principal/interest breakdown) for a loan account. Depends on FIN-025 (loan accounts existing) and FIN-026 (interest calculation method).

## User Story

As a user with a loan,
I want to see the full schedule of upcoming payments (how much goes to principal vs. interest each period),
so that I understand how my loan pays down over time.
