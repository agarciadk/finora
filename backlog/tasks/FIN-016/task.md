# FIN-016 — Rule-based auto-categorization for repeated transactions

## Summary

The inbox asks to let users create rule-based triggers that automatically assign a category to repeated transactions in the future ("Poder crear triggers donde el usuario mediante reglas pueda asignar categorías a movimientos repetidos para futuras ocasiones"). The exact matching criteria for a "rule" aren't specified.

## User Story

As a user,
I want to define a rule once (e.g. "transactions from X are always category Y"),
so that future matching transactions get categorized automatically instead of manually every time.
