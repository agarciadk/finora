# Specification

## Context

"Finora" is used throughout `package.json` names, `README.md`, i18n strings (`sidebar.brand`), the repository name itself, and deployment config (`render.yaml`, Vercel project). A rename is a wide-reaching, low-risk-but-high-surface-area change, and — more importantly — an unresolved naming decision (trademark/domain availability wasn't checked; no candidate name exists yet).

## Functional Requirements

- Open questions (need a decision before this can become `ready`):
  - What is the new name? (Not present anywhere in the inbox or `.ai-context/`.)
  - Does this include renaming the GitHub repository, npm package names (`@finora/eslint-config`), deployed domains (Render/Vercel), and the production database/branding — or only user-facing strings (UI title, i18n)?

## Out of Scope

- Actually executing the rename before a name is chosen.
