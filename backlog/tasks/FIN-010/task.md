# FIN-010 — Dedicated sending email account/domain

## Summary

The inbox asks to add a dedicated email account for sending emails, possibly for a newsletter ("Añadir cuenta de correo para el envío de estos. Posible newsletter"). Split from the newsletter feature itself (FIN-011), since this part is about the sending infrastructure/domain, which is a prerequisite either way.

## User Story

As the product owner,
I want transactional/product emails sent from a dedicated, verified domain,
so that deliverability is reliable and not dependent on a personal/shared inbox.
