# FIN-021 — Recurring payments without a manual "mark as paid" step

## Summary

The inbox asks for recurring payments that don't need a "mark as paid" button ("Pagos recurrentes sin botón marcar pagado"). Today, per `.ai-context/05-current-epic.md`, the Recurring Payments page lets the user mark a payment as paid manually; this idea wants some payments to advance automatically instead.

## User Story

As a user with a fixed, predictable recurring payment (e.g. a subscription always charged on the same day),
I want it to advance to its next due date automatically,
so that I don't have to manually confirm something that always happens the same way.
