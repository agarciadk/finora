# FIN-014 — OAuth2.0 login (Google, Apple)

## Summary

The inbox asks to add OAuth2.0 login with Google and "iOS" ("Añadir Oauth2.0 para inicio de sesión con Google, iOS"). "iOS" almost certainly means Sign in with Apple, but this is an assumption, not a confirmed requirement.

## User Story

As a user,
I want to log in with my Google (and possibly Apple) account,
so that I don't have to create/remember a separate Finora password.
