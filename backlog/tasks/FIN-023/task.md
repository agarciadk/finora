# FIN-023 — Range-selector amount input for recurring payments

## Summary

The inbox tentatively suggests the recurring payment amount input "could be" a range selector ("El selector de importe en pagos recurrentes podría ser un range selector") instead of a plain numeric input. The tentative wording ("podría ser") signals this is a UX suggestion, not a confirmed requirement.

## User Story

As a user creating/editing a recurring payment,
I want an easier way to set the amount,
so that entering it is quicker/more intuitive than typing a number.
